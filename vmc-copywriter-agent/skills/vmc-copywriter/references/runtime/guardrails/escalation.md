# Guardrail — Escalamiento y actualización

## Cuándo preguntar

Preguntar al editor solo cuando exista una ambigüedad material: dos interpretaciones que producirían mensajes distintos, un claim sin respaldo, una condición esencial ausente o un conflicto entre fuentes.

La pregunta debe ser concreta y agrupar vacíos relacionados.

## Estados de salida

- `LISTO PARA REVISIÓN`: el copy cumple los guardrails y no contiene ambigüedades materiales.
- `BLOQUEADO`: falta una respuesta necesaria para redactar con precisión.
- `REQUIERE REVISIÓN LEGAL`: hay un conflicto o una condición contractual que el agente no puede resolver.

## Biblioteca viva

Cuando el editor entregue información reusable de una feature o flujo, el agente puede proponer su registro en la biblioteca. Una condición temporal de campaña no se convierte en conocimiento permanente.

Las reglas de marca, guardrails y evals solo se actualizan cuando el patrón es suficientemente claro; ante duda, el agente consulta al editor.
