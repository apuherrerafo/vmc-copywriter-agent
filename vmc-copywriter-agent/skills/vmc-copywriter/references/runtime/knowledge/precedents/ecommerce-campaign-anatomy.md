# Anatomía de campañas de e-commerce y reventa

## Uso

Esta investigación recoge estructuras de campañas oficiales, no frases para reutilizar. VMC toma la lógica creativa y descarta todas las condiciones específicas del referente.

## Patrones observados

### eBay — posesión que cambia de rol

La entrada comercial no comienza con el formulario: reencuadra una pertenencia que ya no se disfruta como algo que puede entrar en una acción de venta. Después presenta listing, precio, pagos y envíos.

**Patrón útil:** pertenencia personal → nueva utilidad → acción.

**Nunca trasladar:** compradores, pagos, protección, rapidez, fee, envío, escala ni resultados de eBay.

[Página oficial](https://www.ebay.com/sell)

### Vinted — doble recompensa visible

La venta se organiza alrededor de dos consecuencias simultáneas: despejar y obtener una recompensa. La mecánica aparece después como forma de realizar esa transformación.

**Patrón útil:** alivio concreto + posibilidad económica → mecánica.

**Nunca trasladar:** cero fees, pagos, envíos, tracking, protección, comunidad o tiempo de Vinted.

[Página oficial](https://www.vinted.com/how_it_works)

### Etsy — identidad y capacidad antes de herramientas

La página dirige la comunicación a lo que una persona ha creado, seleccionado o conseguido; las herramientas aparecen como soporte para esa iniciativa.

**Patrón útil:** reconocer un criterio o una historia de posesión sin adular de manera vacía.

**Nunca trasladar:** escala, compradores, comisiones, seguridad, alcance internacional o herramientas de Etsy.

[Página oficial](https://www.etsy.com/sell)

## Pregunta obligatoria de transferencia

Antes de usar un patrón, el agente debe responder:

1. ¿Qué emoción humana activa este patrón?
2. ¿Qué hecho de VMC permite expresar esa emoción?
3. ¿Qué claim del referente queda expresamente fuera?
4. ¿La idea seguiría siendo verdadera si nunca se concretara una venta? Si no, no puede usarse.
