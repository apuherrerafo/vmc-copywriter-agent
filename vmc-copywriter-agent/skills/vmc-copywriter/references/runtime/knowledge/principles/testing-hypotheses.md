# Hipótesis y variantes

## Concepto

Una variante A/B solo sirve si prueba una diferencia estratégica observable. Cambiar sinónimos o puntuación sin hipótesis rara vez genera aprendizaje.

## Cuándo ayuda

- Cuando el editor pide A/B.
- Cuando existen dos ángulos plausibles para la misma finalidad.
- Cuando se busca aprender si una pieza responde mejor a claridad, oportunidad, mecanismo o confianza.

## Aplicación en VMC

Cada variante debe indicar internamente qué cambia:

```text
A: enfatiza la posibilidad de publicar.
B: enfatiza recibir propuestas.
```

La entrega al editor seguirá el modo solicitado; no es necesario explicar la hipótesis si no se pide.

## Riesgo

Una variante no prueba conversión por sí misma. La decisión requiere datos reales de entrega, apertura, clic, registro, publicación o la métrica definida para el canal.
