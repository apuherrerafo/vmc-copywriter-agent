# Hoja de estrategia obligatoria

## Propósito

Evitar que el agente pase del insumo a bloques de copy sin decidir qué conflicto humano está resolviendo. Se completa internamente antes de cada borrador comercial; no se muestra salvo `modo diagnóstico`.

## Plantilla

```text
Hecho verdadero del insumo:
Concepto canónico del plan/texto fuente:
Dirección que el editor quiere provocar:
Acción a la que debe conducir:
Emoción / decisión que el editor quiere activar:
Situación actual de la persona:
Tensión humana concreta:
Ganancia deseada:
Costo honesto de postergar:
Mecanismo real de VMC:
Control que conserva la persona:
Gran idea / premisa única:
Emoción primaria:
Emociones secundarias:
Acción real:
Motivaciones confirmadas y cobertura por canal (si aplica):
Referencia aplicada: patrón transferible / elemento de lenguaje o arquitectura / qué queda fuera:
```

## Criterio

Una hoja falla si sustituye cualquiera de estos campos por `publicar`, `visibilidad`, `oportunidad` o `recibir propuestas` sin una consecuencia humana concreta. Esos son mecanismos; no son por sí solos la razón para actuar.

También falla si omite la **emoción / decisión que el editor quiere activar**. Si el editor la entregó, se trata como dirección canónica. Si no la entregó y hay más de una emoción razonable que cambiaría el copy, el workflow pregunta antes de elegir; no la rellena con una etiqueta genérica como `FOMO` sin explicar qué oportunidad, costo o deseo concreto percibe la persona.

También falla si la `Gran idea / premisa única` cambia el concepto canónico, la dirección o la acción que el plan fuente ya estableció. La creatividad transforma la forma de vender el concepto; no lo reemplaza por un nuevo tema.

## Ejemplo de forma — Vendo Mis Cosas

No es copy final ni debe reutilizarse literalmente.

```text
Hecho: se puede publicar un artículo, fijar precio y recibir propuestas.
Situación: hay objetos guardados desde hace tiempo.
Tensión: dinero/liquidez inmovilizada, espacio ocupado y una venta pendiente.
Ganancia: recuperar espacio y abrir una posibilidad económica.
Costo honesto de postergar: mientras el artículo sigue guardado e invisible, esa posibilidad no se activa.
Mecanismo: publicar, fijar expectativa y recibir propuestas.
Control: la persona define el precio esperado y decide cómo continuar.
Motivaciones confirmadas y cobertura por canal: dinero, espacio y reemplazo pueden ser rutas de campaña distintas; una landing puede reconocerlas por bloque sin convertirlas en una promesa.
```
