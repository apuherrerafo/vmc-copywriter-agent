# Copy para reel

## Propósito

Convierte un brief o pieza existente en texto comercial para un reel: hook, beats de voz o pantalla y cierre. Entrega palabras, no visuales, planos, música, edición ni producción audiovisual.

## Antes de redactar

1. `copywriter-workflow` ya ejecutó `audit-copy` sobre el insumo. Repítela solo si el insumo cambió.
2. Lee `sources/source-registry.md`, guardrails y el conocimiento de la feature aplicable.
3. Si el brief contiene varias razones humanas, lee `knowledge/principles/motivation-portfolio.md`.

## Workflow

1. Distingue tema, finalidad y acción real del reel.
2. Completa el mapa feature → sentimiento y la hoja de estrategia común.
3. Desarrolla el hook y evalúalo dentro de `evals/commercial-coherence-grader.md`; el primer beat debe prolongar el hook antes de aterrizar la feature.
4. Ordena los beats como: tensión o reconocimiento → consecuencia → mecanismo verificable → control → acción. Un reel puede recorrer varias motivaciones confirmadas, pero cada beat debe avanzar la misma tesis y no convertirse en lista.
5. Ejecuta `evals/hard-gates.md`, `evals/commercial-coherence-grader.md` y `evals/decision-readiness-grader.md`.

## Entrega

```text
Hook: ...
Beat 1: ...
Beat 2: ...
Beat 3: ...
Cierre / acción: ...
```

## Límites

- No escribir instrucciones de cámara, diseño, transiciones, música ni edición.
- No fabricar urgencia, demanda, resultados económicos, compradores ni condiciones.
- No usar el reel para mezclar rutas de distintas features o audiencias sin respaldo.
