# Juez de reacción humana simulada

## Propósito

Usar una simulación disciplinada para filtrar copy antes de exponerlo a personas reales. No predice conversión ni reemplaza entrevistas, pruebas de cinco segundos, A/B tests o métricas de publicación.

## Preparación

Deriva cada perfil únicamente desde el brief, la feature, la audiencia y frenos confirmados. Cada perfil contiene:

- situación actual concreta;
- objeto o decisión pertinente;
- motivo dominante;
- freno real;
- información que ya conoce.

No inventar ingresos, profesión, edad, urgencia o rasgos psicológicos sin fuente.

## Protocolo ciego

1. Muestra primero solo H1 + línea inmediata + CTA, durante una lectura breve simulada.
2. El juez no ve rúbrica, estrategia, referencias ni explicación del autor antes de reaccionar.
3. Responde en primera persona, cotidiana y sin lenguaje de copywriting:
   - `Entendí que…`
   - `Me importó / no me importó porque…`
   - `La frase que me movió o frenó fue “…”`
   - `Mi siguiente paso sería…`
   - `Postergaría porque…`
4. Luego lee el bloque o pieza completa y registra si la explicación aumenta, mantiene o apaga el impulso inicial.
5. Compara contra el copy fuente o control cuando exista. Solo declara ganador si la razón de avance es más específica, clara y creíble; nunca por cantidad de adjetivos, exclamaciones o supuesta emoción.
6. Antes de aprobar, verifica que el copy transformado conserva el concepto, dirección y acción del plan fuente. El juez rechaza un copy atractivo que cambie de qué trata la pieza.

## Señales mínimas para avanzar

Una reacción cuenta como `MOVERÍA_DECISIÓN` solo si logra, sin ayuda:

1. identificar la acción/producto;
2. nombrar una ganancia o consecuencia propia y específica;
3. citar una frase literal que produjo esa reacción;
4. identificar un siguiente paso disponible;
5. no detectar una promesa falsa o confusa.

Si responde con `suena bien`, `tiene FOMO`, `me gusta el tono` o repite la estrategia sin una reacción propia, el resultado es `ENTIENDE_PERO_POSTERGA`.

## Resultado

```text
Perfil y situación:
Reacción ciega en primera persona:

Acción que entendió:
Ganancia propia nombrada:
Freno / objeción:
Comparación con control:
Resultado: MOVERÍA_DECISIÓN / ENTIENDE_PERO_POSTERGA / DESCONFÍA / FALTA_CONTEXTO
```

## Límite

Un panel simulado es una hipótesis de calidad. La prueba de conversión real corresponde al canal: comprensión humana, CTR, inicio de publicación y publicación completada.
