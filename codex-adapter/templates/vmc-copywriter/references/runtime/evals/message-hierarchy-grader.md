# Evaluador de jerarquía de mensaje

## Propósito

Comprobar que el copy vende una única idea con el orden correcto, en vez de mezclar deseo, mecanismo y CTA o de aplicar una fórmula externa sin relación con el encargo.

## Prueba

1. El run declara un mensaje principal que conserva concepto, dirección y acción del plan fuente.
2. La apertura establece una razón humana para mirar; no presenta primero un proceso o una lista de capacidades.
3. La línea siguiente convierte esa razón en mecanismo verificable de VMC.
4. El CTA nombra la decisión disponible y responde al bloque local.
5. Cada elemento tiene un trabajo distinto; H1, subtítulo y CTA no se parafrasean entre sí.
6. Las fuentes de Copyhackers/CXL/D&AD se usan como método, nunca como evidencia de hechos, resultados, tono VMC o frases copiables.
7. Si el run no cuenta con investigación de cliente real, lo declara como inferencia editorial y conserva `CALIBRATION_REQUIRED` cuando corresponda.

## Resultado

```text
Mensaje principal:
Orden: razón humana → cambio → mecanismo → acción
Trabajos de eyebrow / H1 / resolución / CTA:
Evidencia propia vs. principio externo:
Resultado: EVIDENCE_READY / REWRITE / VETO
Corrección necesaria:
```

`EVIDENCE_READY` exige siete respuestas afirmativas. Una pieza que usa investigación externa como claim, mezcla el trabajo de sus elementos o sustituye la jerarquía por una fórmula recibe `REWRITE`.
