# Investigación aplicada para titulares

## Uso

Esta ficha sintetiza principios para desarrollar trabajo original de VMC. No contiene plantillas para copiar, ni autoriza promesas que VMC no pueda sustentar.

## Qué se incorpora

| Fuente | Principio operacional | Uso en VMC |
|---|---|---|
| John Caples, *Tested Advertising Methods* | El titular carga el interés propio y debe poder probarse. | Evaluar primero si el lector gana, evita o resuelve algo concreto; luego exigir que el subtítulo lo sostenga. |
| Eugene Schwartz, *Breakthrough Advertising* | La fuerza depende de la conciencia y deseo existente del mercado, no de gritar más fuerte. | Partir de una tensión que el editor confirmó; no explicar una feature como si fuera el deseo. |
| Joseph Sugarman, *The Adweek Copywriting Handbook* | La primera frase debe hacer natural leer la siguiente. | Crear un loop de curiosidad que el subtítulo resuelve con el mecanismo real. |
| Chip y Dan Heath, *Made to Stick* | Una idea memorable prioriza, sorprende y se vuelve concreta. | Elegir una sola idea; usar una escena, conducta o contraste que la persona pueda visualizar. |
| David Ogilvy, *Ogilvy on Advertising* | La investigación y la promesa específica preceden a la ornamentación. | Auditar fuente y feature antes de dramatizar; no reemplazar investigación por frases bonitas. |

## Síntesis práctica

Un titular vendedor combina cuatro elementos: una tensión o deseo ya existente, una mirada inesperada pero entendible, una consecuencia personal y una resolución verificable en la línea siguiente.

La técnica no equivale a manipulación. La especificidad y el contraste deben representar una posibilidad real; la única prueba de conversión es la medición posterior en el canal.

## Lecturas de referencia
