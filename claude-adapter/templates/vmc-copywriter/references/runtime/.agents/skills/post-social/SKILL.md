# Copy para post social

## Propósito

Reescribe una publicación existente para redes sociales sin perder su finalidad ni alterar sus hechos. El texto debe generar atención e interés de forma comercial, pero conservar la claridad y condiciones que requiere VMC.

No crea imágenes, reels, carruseles, anuncios pagados ni calendarios de contenido. Para reels, usa la skill `reel`.

## Antes de redactar

1. `copywriter-workflow` ya ejecutó `audit-copy` sobre el texto, imagen, URL o pieza recibida. Esta skill adapta formato; no repite la auditoría salvo que el insumo cambie.
2. Lee `sources/source-registry.md` y los guardrails aplicables.
3. Consulta `knowledge/library/` si el post menciona una feature, término o flujo conocido.

## Workflow

1. Usa el tema y finalidad que entrega el editor; no confundas ambos con el hook del post.
2. Identifica el contexto que el post debe preservar: modalidad, fecha, condición, activo, feature o audiencia.
3. Completa la hoja de diseño persuasivo común y elige una palanca primaria, más una secundaria solo si aporta. Si hay varias motivaciones respaldadas, lee `knowledge/principles/motivation-portfolio.md`: una estática o post trabaja una escena primaria; un paquete pedido por el editor reparte rutas entre activos. El hook y su línea siguiente se evalúan dentro de `evals/commercial-coherence-grader.md`: deben interrumpir, abrir una posibilidad o contrastar una situación con su consecuencia antes de aterrizar la funcionalidad. La primera línea debe hacer sentir la relevancia; no solo anunciar la feature.
4. Desarrolla la idea con lenguaje concreto: qué oportunidad, flujo o acción existe y qué puede hacer la persona. Usa el mecanismo verdadero para sostener la emoción.
5. Cierra con la acción adecuada al objetivo, solo cuando la pieza requiera una acción.
6. Ejecuta `evals/hard-gates.md`, `evals/commercial-coherence-grader.md` y `evals/decision-readiness-grader.md`. Revisa que el desarrollo no diluya el hook y que el post no dependa de FOMO, urgencia, precios, ahorro o escasez que no tengan respaldo.

## Estructura flexible

Trabaja los bloques que correspondan, sin forzar una plantilla:

```text
Hook
Desarrollo
Condición o contexto relevante
Acción / cierre
```

El hook no debe repetir en otras palabras todo el desarrollo. El cierre no debe afirmar una acción que el usuario no puede realizar.

## Entrega

Por defecto, entrega solo una versión final lista para publicar. Conserva hashtags, menciones o links existentes cuando estén confirmados; no agregues tendencias ni hashtags genéricos por relleno.

Usa `modo variantes` para probar ángulos distintos —no cambios superficiales de sinónimos— cuando el editor lo pida.

## Límites

- No crear diseño, guion audiovisual, piezas gráficas ni pauta.
- No prometer resultado económico, precio, condición, plazo, garantía o financiamiento sin fuente.
- No usar `remate` ni lenguaje que presente una publicación como una compra o transferencia ya cerrada.
