# Evidencia de ejecuciones

Los run records son artefactos de evaluación. Cada entrega de copy registra aquí el input, estrategia, fallos, rondas y estado final mediante la plantilla de `.agents/skills/copywriter-workflow/references/run-record.md`.

`archive/` contiene runs históricos rechazados o invalidados. Nunca se usa como biblioteca creativa ni como evidencia de aprobación.
