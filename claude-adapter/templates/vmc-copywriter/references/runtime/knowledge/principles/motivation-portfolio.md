# Cobertura de motivaciones

## Propósito

Evitar que una motivación válida se convierta, por inercia, en la única razón humana de una campaña. Este marco decide **qué motivación trabaja cada pieza**; no obliga a mencionar todas en cada texto.

## Mapa previo

Antes de redactar, anotar únicamente las motivaciones que el brief, el conocimiento de la feature o una fuente confirmada sostengan:

```text
Motivación verificable:
Persona / momento:
Cambio que busca:
Mecanismo real que la feature habilita:
Límite de lo que no se puede prometer:
```

Ejemplo conceptual de venta entre personas: obtener dinero para algo puntual, recuperar espacio, dejar ir algo sin uso o hacer lugar para una compra/cambio. Son rutas posibles, no una lista que deba trasladarse a otra feature ni una promesa de resultado.

## Elegir cobertura por pieza

| Pieza | Cobertura recomendada |
|---|---|
| Landing | Una tesis principal en el hero. Puede desarrollar dos o más motivaciones confirmadas en bloques distintos si ayudan a que más personas se reconozcan; no las apila como una lista en el H1. |
| Email | Una motivación primaria por envío. Puede haber otro email o una variante con otro ángulo si la campaña lo necesita. Solo combina rutas cuando la progresión las hace legibles. |
| Post, banner o estática | Una motivación y una escena por pieza. Para un paquete pedido por el editor, repartir rutas entre piezas; no crear variaciones superficiales del mismo dolor. |
| Story, carrusel o reel | Puede recorrer varias motivaciones, una por beat o pantalla, siempre que todas conduzcan a la misma acción real. La secuencia no es una lista de beneficios. |
| UX comercial | Trabajar solo la motivación pertinente a ese estado. En errores, pagos, restricciones y confirmaciones prima precisión. |

## Decisión

1. Si el brief define una necesidad concreta, úsala como ruta primaria.
2. Si la pieza busca reconocimiento amplio y existen varias motivaciones respaldadas, selecciona una tesis paraguas y distribuye rutas complementarias por bloque o secuencia.
3. Si se solicita una campaña o varias estáticas, asigna una ruta diferente a cada activo y declara internamente qué hipótesis prueba cada una.
4. Si no hay evidencia para una motivación, no la inventes para completar variedad.

## Límites

- Variar motivaciones no permite prometer dinero, venta, compradores, rapidez, ahorro, espacio liberado ni resultados de terceros.
- La motivación humana cambia entre features; nunca se transportan literalmente ángulos, frases o supuestos de otra campaña.
- Una cobertura amplia no reemplaza una gran idea: cada pieza debe poder expresar su tesis en una frase.
