# Posicionamiento contextual

## Concepto

Antes de prometer, aclarar qué es la propuesta, para quién sirve, en qué situación importa y qué mecanismo o diferencia verificable la hace relevante.

## Cuándo ayuda

- Cuando una feature o landing se explica con frases genéricas.
- Cuando hay que diferenciar una publicación de usuario de una propuesta para empresa.
- Cuando el beneficio depende del contexto de la persona.

## Aplicación en VMC

Una pieza debe ayudar a entender si comunica una modalidad de oferta, una herramienta para publicar, una acción para vender o un flujo para participar. No usar un mismo mensaje para todas esas situaciones.

## Riesgo

No comparar con competidores, alternativas o resultados sin evidencia. No convertir una diferencia de flujo en una ventaja absoluta.
