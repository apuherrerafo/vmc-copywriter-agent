# Principios de copywriting

## Rol dentro del agente

Esta carpeta contiene principios estratégicos que ayudan a decidir el ángulo, nivel de conciencia, prueba, emoción y estructura del copy. No reemplaza:

- `knowledge/library/` para hechos de features de VMC;
- `guardrails/` para límites obligatorios;
- `.agents/skills/` para el workflow de cada canal;
- `evals/` para comprobar resultados.

Principio operativo adicional: `emotional-levers.md` define cómo usar deseo, FOMO factual o de oportunidad, identidad, control y otros disparadores sin fabricar claims.

`feature-to-feeling.md` convierte hechos de cualquier feature en una tesis humana específica y evita transportar el ángulo de una campaña a otra.

`motivation-portfolio.md` decide si una pieza trabaja una motivación, varias rutas por bloque o una secuencia. Evita que una motivación válida monopolice una campaña por costumbre.

Para H1, asuntos, hooks y primeros frames, `headlines-and-big-ideas.md` reúne principios propios de publicidad/copy de respuesta directa: gran idea, interés propio, concreción y curiosidad resuelta.

Los precedentes externos de e-commerce se guardan fuera de esta carpeta, en `knowledge/precedents/`, porque inspiran arquitectura y territorios de idea; nunca establecen hechos de VMC ni copy reutilizable.

## Uso

El agente consulta solo los principios relevantes a la pieza. No debe aplicar una fórmula completa ni todos los principios a cada copy.

Cada principio propio se guardará como una ficha con:

- concepto;
- cuándo ayuda;
- cuándo evitarlo;
- aplicación posible en VMC;
- riesgo o guardrail asociado;
- fuente y fecha de revisión.

## Derechos y método

No se copian ni cargan libros completos. Se crean fichas originales y breves basadas en conceptos, ejemplos propios de VMC y fuentes identificadas. Las fuentes son inspiración y criterio; no sustituyen los T&C ni los hechos de la pieza.

## Canon inicial propuesto

### Base rescatada del Drive compartido

El archivo `copywriting_principles.md` del Drive se basaba explícitamente en *Breakthrough Advertising* de Eugene M. Schwartz.

Principios que sí se rescatan:

- nivel de conciencia del usuario;
- deseo existente: conectar una necesidad real con una propuesta verificable;
- sofisticación del mercado: diferenciar con mecanismo o prueba, no solo con adjetivos;
- especificidad y creencia: una afirmación requiere una razón para ser creíble.

Principios que no se importan como reglas de VMC:

- ejemplos, audiencia, tono y producto de Vibreli;
- supuestos sobre ciclismo o su mercado;
- longitudes fijas de email;
- la regla universal de un CTA para cualquier tipo de pieza.

Fuente de referencia: *Breakthrough Advertising*, Eugene M. Schwartz.

### Cinco insumos complementarios candidatos

| Fuente | Aporte para VMC | Límite de uso |
|---|---|---|
| *Influence*, Robert Cialdini | Prueba social, consistencia, autoridad y reciprocidad ética | Nunca fabricar prueba social, autoridad, cupos ni escasez |
| *Tested Advertising Methods*, John Caples | Formular hipótesis y probar hooks/ángulos en A/B | Una variante debe probar una hipótesis real, no sinónimos |
| *Ogilvy on Advertising*, David Ogilvy | Investigación previa, beneficios concretos y claridad comercial | No convertir máximas históricas en reglas universales |
| *Obviously Awesome*, April Dunford | Posicionamiento: para quién, frente a qué alternativa y por qué importa | Aplicar solo cuando haya contexto suficiente de la oferta o feature |
| *Everybody Writes*, Ann Handley | Voz humana, utilidad y escritura clara para contenido digital | No usar tono “amigable” si contradice contexto, T&C o marca |

### Sexta fuente opcional: ciencia conductual

*Using Behavioral Science in Marketing*, Nancy Harhut, puede sumar principios de comportamiento y atención. Se usará como apoyo para diseñar fricción, claridad y prompts éticos; no como excusa para manipulación ni para afirmaciones de “neuromarketing”.
