# De feature a sentimiento comercial

## Propósito

Convertir hechos de cualquier feature, línea de negocio o campaña en una tesis emocional propia. Este marco es reusable: la lógica viaja; los ángulos, palabras y promesas de una feature no.

## Mapa de decisión

Antes de crear un título, asunto, hook o cuerpo comercial, derivar desde el encargo:

```text
Persona y momento actual:
Qué intenta resolver, conseguir o evitar:
Qué cuesta —práctica o emocionalmente— dejarlo igual:
Qué cambio desea experimentar:
Qué hecho o mecanismo de la feature hace posible ese cambio:
Qué control conserva la persona:
Qué resultado depende de terceros y no se puede prometer:
```

La `feature` es el mecanismo; la `verdad humana` es la razón para escuchar. Si el mapa queda genérico, recuperar contexto antes de recurrir a palabras como dinero, espacio, oportunidad, rapidez o confianza.

## Selección de palanca

Elegir la palanca que nace del mapa, no de una lista fija:

| Si la verdad humana es… | Palanca que podría encajar |
|---|---|
| una necesidad presente con una alternativa disponible | alerta / costo de oportunidad |
| deseo de mejorar, estrenar o avanzar | anticipación / futuro deseable |
| duda antes de una decisión material | control / reducción de incertidumbre |
| un recurso que permanece inactivo | contraste / activación |
| una pertenencia, logro o esfuerzo previo | reconocimiento / segunda función |
| un cambio de etapa u organización | alivio / renovación |

No forzar una palanca si el insumo no la sustenta. Un copy puede ser sereno cuando la decisión no necesita alta intensidad.

## Transferencia entre negocios y canales

- **Universal:** escena humana → tensión o deseo → cambio deseado → mecanismo verificable → control → acción.
- **Variable:** situación, emoción, vocabulario, claims, audiencia, prueba y CTA de cada feature.
- **Canal:** el mismo hilo se comprime en asunto, hook, banner o primera story; se desarrolla por bloques en email y landing; se usa con ligereza en UX comercial.

Ejemplo conceptual: una publicación puede trabajar dinero disponible; una subasta puede trabajar preparación para participar; una feature empresarial puede trabajar recuperación de activos. El sistema no reutiliza el copy ni presupone que las tres personas sienten lo mismo.

## Regla de cuerpo

La primera línea abre la tensión; el resto de la pieza debe demostrarla, hacerla personal, devolver control y aterrizar el mecanismo. Si después del hook el cuerpo puede convertirse en centro de ayuda sin perder efecto, falta persuasión.
