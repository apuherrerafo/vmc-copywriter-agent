# Compuerta de cobertura de motivaciones

## Cuándo se usa

Se ejecuta cuando el brief contiene más de una motivación humana legítima, cuando una landing desarrolla varias rutas o cuando se solicita un paquete de piezas. No obliga a forzar variedad en un activo con una necesidad única y clara.

## Gate bloqueante

1. **Mapa con evidencia:** cada motivación usada procede del brief, feature o fuente confirmada.
2. **Elección consciente:** la pieza define si trabaja una ruta, una combinación o una secuencia y por qué ese formato lo requiere.
3. **Tesis legible:** hay una motivación primaria o una tesis paraguas; el copy no se convierte en inventario de dolores.
4. **Cobertura de landing:** si la landing habla a distintos momentos válidos, cada bloque añade una ruta o función distinta sin repetir el mismo dolor con sinónimos.
5. **Foco de activo corto:** email, post o estática sostiene una escena primaria; las variantes o piezas de campaña prueban rutas distintas, no duplicados cosméticos.
6. **Progresión de secuencia:** story, carrusel o reel ordena las rutas como beats que llegan a una misma acción, no como lista.
7. **Límite factual:** ninguna ruta se formula como resultado garantizado.

## Resultado

`EVIDENCE_READY` exige siete respuestas afirmativas. Si una motivación monopoliza la pieza sin que el brief lo justifique, o la variedad se vuelve una lista, el resultado es `REWRITE`.

```text
Rutas confirmadas:
Cobertura elegida y motivo:
Tesis primaria / paraguas:
Evidencia por bloque o activo:
Límite factual:
Resultado: EVIDENCE_READY / REWRITE / VETO
```
